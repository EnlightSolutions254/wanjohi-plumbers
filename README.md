# Wanjohi Plumbers Website

Production-ready static website refactor for Wanjohi Plumbers.

## Structure

- `index.html` - semantic HTML document
- `css/style.css` - base styles and components
- `css/responsive.css` - responsive breakpoints
- `css/animations.css` - reveal, counter, keyframe, and reduced-motion styles
- `js/app.js` - application entry point
- `js/navigation.js` - header and mobile navigation behavior
- `js/faq.js` - FAQ accordion behavior
- `js/animations.js` - reveal and count-up interactions
- `images/` - local image assets and placeholders
- `fonts/` - reserved for self-hosted fonts
- `assets/` - reserved for extra static assets

## Image Notes

Remote production image URLs were replaced with local SVG placeholders. Replace these with optimized local photos before launch:

- `images/hero/hero-plumber.svg`
- `images/services/service-feature.svg`
- `images/team/plumber-installation.svg`
- `images/services/bathroom-fixture.svg`

Recommended production formats: AVIF/WebP with JPEG fallback where needed.

## Development

This is a static site. Open `index.html` directly or serve the folder with any local static server.
